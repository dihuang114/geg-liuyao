# 鸽阁六爻

鸽阁六爻是一款完全免费的六爻排盘与卦例管理工具。拥有点击切换用神、记录反馈与回访、生成应期、卦例数据分析、按求测人与起卦方式筛选卦例、本地导出导入表格或JSON格式卦例等特色功能。

## 主要功能

- **排盘**支持六爻和梅花易数。可查看卦盘、用神与世应、十二长生、神煞及卦辞爻辞。
- **卦例档案**支持按种类、求测人及起卦方式查找或修改，可填写卦例的结果好坏、断卦的准确度与详细反馈。支持相似卦例对照与到期回访提醒。
- **导入与备份**支持导入 CSV 和 XLSX。完整 JSON 备份可在不同设备间迁移所有应用数据，如卦例、反馈、分组和设置。
- **数据分析**支持实时分析档案中保存的卦例，可探究爻位动频、卦宫分布等。
- **复制与分享**可复制排盘内容或用于解卦的 AI 提示词。支持截图分享，并支持隐藏求测人及问题。
- **设置**支持设置自动保存卦盘、截图自动匿名、黑夜模式、干支彩色模式、神煞管理和字体等。

| 平台 | 文件 | 使用方法 |
| --- | --- | --- |

| Windows x64 完整版 | `GEGLiuyao-1.0.1-Windows-x64.zip` | 解压整个压缩包，再运行 `Liuyao.exe` |
| 安卓正式版 | `GEGLiuyao-1.0.1-Android.apk` | 下载 APK 后在设备上打开安装 |
